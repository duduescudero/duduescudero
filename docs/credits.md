# Créditos

- Banner, introdução animada, botões, molduras e painel de atividade: composição própria para Eduardo Escudero, com apoio de IA.
- Capturas reais: Fluxo OS, Meu Onze, OrbitaVerde e PokeIdle Manager, reutilizadas do portfólio. Dados demonstrativos preservados. Os originais estão em `assets/screens/`; `scripts/build-visuals.mjs` reproduz as composições.
- Ícones: [Skill Icons](https://github.com/tandpfun/skill-icons), revisão `7f7e691e71aec64e8354bf697835e009d1ad80f8`, licença MIT preservada em `assets/icons/LICENSE`. As marcas pertencem a seus respectivos titulares.
- Cobrinha: [Platane/snk](https://github.com/Platane/snk), revisão `d8f6715049803e982ee5ff501b6b9b7d5deeb09b`, com cores próprias e calendário de `duduescudero`.
- Indicadores: GitHub GraphQL API e distribuição de código pelo GitHub Linguist.

O README de Luan Macea foi consultado como referência de organização visual. Seus textos, capturas e dados profissionais não foram incorporados.
